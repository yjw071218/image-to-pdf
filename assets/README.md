# Logo

`logo.png` is the original transparent PNG. `app.ico` contains Windows icon sizes from 16 to 256 pixels. The original composition was generated using the built-in image generation tool and then refined with that same tool. ICO conversion uses `tools/make-icon.ps1`.

Generation prompt:

> Use case: logo-brand. Asset type: Windows application icon and GitHub project logo for ImageToPDF, an app that orders images and binds them into a PDF. Create one polished, minimal, vector-like app emblem: a neat stack of three rounded image/document sheets becoming one bound document, with a simple mountain and sun pictogram on the front sheet. Bold readable silhouette at 32 pixels, crisp edges, balanced centered square composition with generous safe margin. Modern restrained blue/teal with a small warm red document accent. No letters, no words, no watermark, no mockup. Transparent background outside the emblem. Output one square high-resolution PNG.

Final refinement prompt:

> Edit this app logo. Keep the three image sheets, arrow, red folded document, composition, colors and transparent background unchanged. Replace only the red looping Acrobat-like symbol on the front white document with three simple straight horizontal red text lines of descending length. There must be no Acrobat symbol or any other existing brand mark. No text or letters. Preserve true transparency. This is the final original app logo.
