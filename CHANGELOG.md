# Changelog

## 2.0.0

- Combine PDFs and images in one page-oriented editor; preview actual PDF pages.
- Delete specific pages using the list or page ranges, and extract selected pages.
- Rotate, duplicate, insert blank pages, select odd/even pages, undo and redo (50 steps).
- Default image layout: A4, centered, proportional fit with white padding and no cropping.
- A3, A5, ISO B4/B5, Letter, Legal, custom sizes and original image size; portrait, landscape, automatic orientation and margins.
- Image quality/DPI controls and persistent paper settings.
- Multi-page TIFF import; open password-protected PDFs (including AES) with a supplied password.
- Background import/export, cancellation, original-file protection and atomic output.
- PDF context-menu registration, isolated regression tests and expanded third-party license bundle.

## 1.0.0

- Windows Explorer context menu for combining selected images into a PDF.
- Korean interface with preview, multi-item move up/down, natural filename sorting, reverse and remove.
- JPG, PNG, BMP, GIF, TIFF and WebP support, transparency flattening and EXIF orientation.
- Atomic output replacement to preserve existing files when conversion fails.
- Original logo, multi-resolution Windows icon and per-user installer with uninstall support.
- Self-contained Windows x64 installer and portable distribution; no separate Python installation required.
